# WIT-A Auth Modules (Index, Register, Login, Forgot Password) - PostgreSQL

1. Create the `users` table in your PostgreSQL database: run `backend/schema.sql`
2. Check `backend/.env` (DATABASE_URL, JWT_SECRET, PORT)
3. cd backend
4. npm install
5. npm start
6. Open http://localhost:5000  (do NOT open the .html files by double-click)
